# 世界引擎 v3.3.5

保留新版双引擎界面，修复实际运行与交互中发现的问题。本次也修复了检查自动推演链路时发现的既有边界问题。

## 自动推演

- 每 X 轮推演以最近一次成功更新的位置计数，不再重复计算上一份存档点之后已经处理过的回复。达到或超过阈值都可继续，避免停用或失败后错过触发点。
- 计数按实际 AI 回复进行，排除开场白、系统消息和空消息。没有 AI 开场白、首轮只有两条消息的聊天也能自动更新。
- `regenerate` 开始时清理旧去重键，不依赖额外的 swipe 事件；生成开始时撤销上一条回复尚未执行的定时任务。
- 顶部显示真实的自动、手动或停用状态，点击可进入推演设置。注入开关继续独立控制提示词注入。

## API 响应

直连请求显式发送 `stream: false`。三个连接入口共用答案文本提取，兼容字符串、文本块数组、旧式 completions 文本、output 文本和常见包装结构。对于接口直接返回的世界状态 JSON 或记忆任务 JSON，按引擎字段识别后原样传给后续解析，不再强制要求 `choices[0].message.content` 外壳。HTTP 响应也兼容供应商仍返回 SSE 的情况，合并文本增量并避免重复拼接最终快照；这些是响应格式兼容，不改变请求协议或端点。

不把 reasoning/thinking 或工具参数当成最终答案。真正的空响应、只返回推理、模型拒绝、未识别结构与解析失败分别提示原因，失败响应仍通过原有错误记录脱敏保留。

## 界面

- 离开世界卡片编辑页后清理旧编辑状态，避免后续自动刷新一直被隐藏的编辑状态拦截；仍在编辑时继续保护输入。
- 设置保存栏移到滚动区外，避免遮挡记忆 API 下拉按钮等控件。
- 世界、记忆任务开始和结束时立即同步底部按钮，运行期间提供停止入口并禁用重复任务。没有存档点时禁用重演。
- 总述生成失败显示原因，不再只写控制台；清理隐藏的旧标题、旧关闭按钮和旧设置入口。
- 分类和底部操作状态未变化时保留原按钮节点。

## 验证

`docs/*test.js` 覆盖核心、API、记忆、世界历史、回退、联动、实体 ID 和剧情时间。其中新增 `world-api-response-test.js` 检查三个连接入口的响应提取、SSE、错误分类及脱敏。

三个浏览器测试使用独立临时浏览器、合成聊天和隔离存储，不请求真实供应商、不写真实聊天：

- `ui-functional-browser-test.mjs`：加载真实主入口及全部模块，测试连续自动更新、每 X 轮、重生成、无开场白、去重、停用恢复、直接 JSON 与文本块答案落盘、六类新增卡片、时间编辑、记忆提取与总述，以及后台更新不覆盖设置输入。
- `world-api-routing-browser-test.mjs`：点击可见的新引擎切换按钮，验证双引擎 API 多选、实际保存、等待中修改 RPM，以及 360px 浅色主题。
- `world-backfill-ui-browser-test.mjs`：25 批更新、运行中保存设置与重开面板、引擎切换、停止、续传入口与进度清理。

浏览器测试支持传入本机 puppeteer 模块（或模块 file URL）和 Chrome 路径，例如：

```text
node docs/ui-functional-browser-test.mjs [puppeteer 模块] [Chrome 路径]
```

更新插件后刷新酒馆页面；若浏览器仍保留旧脚本，使用 Ctrl+F5 强制刷新。
