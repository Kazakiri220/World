Phase 3 & Phase 4 核心设计说明

告别“进进出出”，随时平级切换

1. 常驻二级分类胶囊栏 (Category Chips) 原本在主界面看“事件”或“仇敌”，必须“点进子页 ➜ 看完点返回 ➜ 再点另一项”，非常繁琐。
现在上方常驻 `[ 总览 ]` `[ 局势 ]` `[ 事件 ]` `[ 关系 ]` `[ 资源 ]`，在任何界面直接横向一键点击切换，零等待、零多余返回！
2. 核心圆环瘦身微缩 (节省 35% 垂直空间) 原本 160px+ 高度的巨型圆环把内容全部顶到屏幕下方。新设计将圆环缩减至精致仪表盘尺度，稳定度百分比和核心统计一目了然，腾出大幅空间直接阅读剧情。
3. 底部常驻推演操作条 (Quick Action Bar) 彻底解决用户“找半天推演按钮在哪里”的问题：无需在小球外圈猜测无文字的卫星图标，只要面板打开，底部常驻 `[ ▶ 立即单步推演 ]`、`[ 🔄 重演当前轮 ]`、`[ ⚡ 注入开/关 ]`。
4. 双引擎自适应对齐 切换到「记忆引擎」时，胶囊栏自动切换为 `[ 脉络 ]` `[ 人物 ]` `[ 实体 ]` `[ 纪要 ]` `[ 总述 ]`，底部动作也相应切换为提取记忆与生成总述，体验完全统一。
