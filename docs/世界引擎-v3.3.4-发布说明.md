# 世界引擎 v3.3.4

修复批量更新的进度停在旧数字的问题：重新打开面板、切换引擎界面等操作会重建界面，原任务却一直向已经脱离页面的旧节点写入。现在任务保存最新显示状态，每次更新重新查找当前节点，重建面板时立即恢复最新进度。运行中保存 RPM 设置后可以重新进入面板查看，不会丢失显示进度。

悬浮球随批次开始、重试和完成同步显示当前批次；切回世界界面恢复后台推进后的数字。完成或停止后清理旧计数，保留最终提示和续传入口。运行中禁用重复启动入口。

新增真实完整面板的浏览器回归：使用 25 批合成对话，在第 17 批保存设置并重开面板，验证新节点继续显示 18/25；同时覆盖再次重开面板、切换世界和记忆界面、完成、停止及续传入口。全部聊天、存储与 API 响应均为内存夹具，不访问真实聊天或供应商。

此版本同时包含 v3.3.3 的修复：等待中的 API 请求约每秒读取最新保存的全局 RPM，保存为 0 后可以恢复；供应商限流冷却单独标明。
