为什么这样重组更高效？

1. 8 Tab ➔ 4 Tab，彻底消灭横向滚动 原本在 420px 下需要点左右箭头横滑才能找齐 8 个 Tab。现在 4 等分平铺，手指或鼠标一点即达，任何模块都不再被遮挡。
2. 原被“藏匿”的高频功能全面归位 • API 自动重试：从「高级」移回「API 配置」正下方。
• 批量重填：从「高级」移回「存档与历史」生命周期中。
• Prompt 预设定制：从「调试」最底层解救出来，给予醒目入口。
3. 新增「设置即时过滤搜索框」 在设置顶部输入关键词（如 骰子、重填、API、注入），所有卡片实时精准过滤，彻底解决“找半天”的痛点！
4. 顶部直观双核切换器 (Segmented Switch) 将原本隐蔽的“点击标题 3D 翻转”升级为顶部直接可见的胶囊双选按钮，再也不会不知道当前在配置世界还是记忆。
5. 视觉升级：卡片化 + 优雅 Switch 开关 告别灰暗密集的“表单堆叠”，采用卡片独立封装、发光边框和圆角开关，高频参数置顶，微调参数折叠收纳。
