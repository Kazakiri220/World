# 世界引擎 v3.2.0

## 剧情时间标注

- 世界状态增加当前剧情时间。事件、势力、风声、大势、仇敌、影响链、区域事件、经济及信号、声誉和黑盒条目增加时间信息。
- 分别保存首次记录、最近实质变化、实际发生及预计／截止时间。首次记录不代表事件刚刚发生；已经结束的事件，其时间也保存在重大事件账本中。
- 在既有世界推演请求中同时提取本次正文的当前场景时间，无额外 API 请求。要求模型返回原文依据，本地检查依据是否包含于本次处理的正文；没有有效依据时沿用上次时间并标明来源，或保持未知。
- 保留原始精度与纪年，可保存不完整日期、时间范围和虚构纪年。提示词要求排除回忆、计划与假设日期；语义识别依赖模型判断，本地原文核验不能保证日期理解正确，可在面板修正。
- 模型通过临时 changed 标记说明描述是否新增事实。本地结合阶段等状态变化判断是否更新最近变化时间；仅进度计数、重复返回或改写描述不刷新。临时标记不保存。
- 面板顶部与世界摘要显示剧情时间。各条目的“时间详情／修改”支持查看来源及手动修正，留空为未知。手动修正的发生、预计时间不会被后续模型返回覆盖，除非用户再次修改或清空。
- 后台推演、正文注入和重大事件账本携带时间。注入仍受原有总字符数限制，不将整份历史注入正文。

## 兼容与范围

- 本版继续使用现有按轮推进、持续／冷却、骰子和调度机制；时间标注不会把轮数换算成天数。原有“按时间推演”模式的数值时间字段独立保留。
- 回填只读取当前批次的历史正文。世界快照包含时间字段，删除回退、原生分支和 checkpoint 随状态一起恢复。
- 旧条目缺失的时间保持未知，不用升级时间或电脑时间补填。手动编辑聊天正文不会触发世界更新或作废历史。
- 暂不直接读取数据库插件的内部数据，也不修改其模板或聊天中的数据库字段。时间来源受已有正文过滤设置影响；被过滤掉的时间不会进入提取上下文。
- 本版从成功更新后开始积累时间标注；不会自动重算旧历史。需要为历史阶段补充时间时，可以使用已有范围更新功能。

## 验证

新增离线测试使用真实世界合并、注入、账本、历史模块和面板处理器，覆盖延迟获知事件、重复改写、阶段变化、原文依据、未知与沿用、虚构纪年、旧数据、人工修正、历史回填及中断续传、分支和删除恢复、面板转义及存档点隔离。

未调用真实供应商 API，未操作现有 SillyTavern 聊天文件；真实模型提取效果及酒馆内交互仍需实际使用检验。
