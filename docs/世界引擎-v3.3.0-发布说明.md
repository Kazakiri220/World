# 世界引擎 v3.3.0 / 记忆引擎 v1.2.0

## 多 API 负载均衡

在世界或记忆引擎的 API 设置中启用“多 API 负载均衡”，勾选连接并保存设置。可以混选本插件已保存的自定义连接及酒馆 Connection Profiles。未开启时继续使用原来的单连接配置。

- 按列表顺序轮换，请求成功后下一次使用下一条；连接超时、HTTP 错误、空内容等失败时，尝试下一条连接。
- 每次请求最多尝试连接池一遍；全部失败后由原有 API 重试及批量重试设置决定是否重试。模型内容格式解析失败仍由原有解析／重试流程处理。
- 使用各连接保存的模型、地址和密钥，温度及输出上限使用所属引擎的设置。修改自定义连接后须点击“更新连接”。不切换酒馆正文连接，也不套用正文生成预设。
- “请求超时（秒）”同时控制轮换等待时长，默认 120 秒，0 表示不限时。超时覆盖响应头和正文读取；即使服务忽略取消，插件也会停止等待并丢弃迟到结果。上游服务是否实际终止运算取决于服务端。
- 推演顺序请求，仅成功结果提交世界；故障转移不会额外增加世界轮次。全部失败保留原范围更新断点。
- 世界与记忆分别保存连接池及轮换位置。轮换位置和计数属于当前页面，刷新后重新开始。

## RPM

- “本引擎每分钟最多请求数”控制该引擎所有连接的请求总量；每条连接右侧的 RPM 控制该连接的额度。两种上限同时生效，默认均为 0，即不限制。
- 总 RPM 随引擎设置保存；单连接 RPM 修改后即时保存，世界与记忆共用。自定义连接中相同地址、相同密钥的别名共用计数，并采用其中最小的正上限；酒馆配置按配置 ID 计数。
- 使用滚动 60 秒窗口，失败、重试和故障切换尝试也计数。有其他可用连接时跳过已用满额度的连接；所有连接都受限时等待最早可用的额度。
- 等待额度不消耗请求超时，可以停止任务。取消等待或当前请求后不会再切换连接，也不会在稍后自动补发。
- 遇到 429／明确的限流错误，按响应中的 Retry-After 暂停使用该连接；没有该信息时默认等待 60 秒，期间优先使用其他连接。
- 计数覆盖当前页面中本插件的生成、推演、记忆及连接测试请求，不计手动获取模型列表。其他标签页、正文、数据库插件及外部程序的请求不在计数内；服务商按账号合并的额度需要结合总 RPM 设置。

## API 报错详情

- API 设置下方可展开报错记录，包含发生时间、连接、HTTP 状态及供应商错误正文。切换成功后也保留此前失败记录。
- 全局最多保留最近 20 条，单条正文最多 65536 个字符；可以按引擎清理。记录保存在本设备全局存储，不加入世界历史或聊天快照。
- 酒馆配置模式会展开请求服务提供的 cause，展示其可用错误原因；酒馆服务没有提供的响应正文无法恢复。
- 已知 API 密钥及常见鉴权字段脱敏，供应商返回的 HTML 按文本展示。报错记录写入失败时保留当前页面的内存记录，并继续尝试下一条连接。
- 获取模型列表发生的错误同样记录；重试状态提示包含错误原因。

## 验证

新增离线测试覆盖混合连接轮换、并发申请公平、请求／响应正文超时、迟到丢弃、总 RPM、连接 RPM、别名及跨引擎计数、取消等待、429 冷却、HTTP 与业务错误、酒馆 cause、错误脱敏／转义、表单保存和分引擎清理。使用真实世界回填及历史模块验证了成功只提交一次、失败保留断点，以及限流等待期间停止任务。
