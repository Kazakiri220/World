# 世界引擎 v3.3.2 / 记忆引擎 v1.2.2

针对选择负载均衡 API 时页面卡死、浏览器提示 `STATUS_BREAKPOINT` 的报告，替换了下拉框的交互实现：用普通按钮控制菜单显隐，移除原生 `details/summary` 和失焦时自动折叠的处理。下拉多选的布局与全局 RPM 设置继续保留。

勾选时只修改已有文本节点和选中样式，不重建摘要、不重新读取连接库，保留焦点及菜单滚动位置。点击外部和按 Esc 仍可收起菜单，方向键可进入选项。

补充完整插件面板的浏览器回归，覆盖世界与记忆两个界面连续选择第一、第二项、混选酒馆预设、滚动、保存后恢复及窄屏显示。

验证使用了 Brave 1.97.59（Chromium 155.0.8059.85），并直接访问本机酒馆，在 305 层实际对话中对两个界面各连续勾选 14 次。调试时拦截写入接口，全部 455 个聊天文件前后的 SHA-256 一致，无新增、删除或修改。Chrome 和 Edge 的完整离线面板测试及 18 个回归脚本也已通过。

原始浏览器崩溃未在调试窗口中复现。更新本机插件后，使用者已在原来的 Brave 窗口刷新并连续选择第一、第二个连接，确认不再崩溃；具体的浏览器内部触发机制尚未确定。

浏览器测试命令：`node docs/world-api-routing-browser-test.mjs [puppeteer 模块名或 file: URL] [Chrome 路径]`。测试使用内存中的合成聊天与连接，禁止网络请求，不打开真实酒馆聊天。
